# NONFICTION 클론코딩

향수 브랜드 논픽션(NONFICTION) 공식 사이트를 참고해 메인과 상품 상세 페이지를 구현했습니다.
디자인과 이미지의 저작권은 원 브랜드에 있으며 포트폴리오 용도로만 사용했습니다.

## 프로젝트 정보

- 작업 유형: 개인 클론코딩
- 사용 기술: HTML, CSS, JavaScript, Swiper
- 폰트: Playfair Display

## 페이지 구성

- 메인: 헤더, 배너 슬라이드, 상품 목록, 브랜드 콘텐츠, 푸터
- 상품 상세: 상품 정보, 옵션·수량 선택, 추천 상품
- 장바구니: 메인과 상세 페이지에서 함께 사용하는 장바구니 패널

## 작업한 내용

- 스크롤 반응형 고정 헤더와 이미지 메가 메뉴
- Swiper를 활용한 메인 배너·향수 소개 슬라이드
- 상품 카드 호버 시 이미지 전환 및 장바구니 버튼 노출
- 반응형 상품 그리드: PC 4열·태블릿 3열·모바일 2열
- 하나의 `detail.html`로 6개 상품과 옵션 정보 연결
- 옵션·수량 선택에 따른 가격 변경
- `localStorage`를 활용한 메인·상세 공통 장바구니
- 모바일 메뉴·하단 구매 버튼·키보드 포커스·ARIA 상태 적용
- 티어스 인 레인·네롤리 드림의 향 노트와 스토리 구성

## 폴더 구조

```
nonfiction_portfolio
├─ index.html
├─ detail.html
├─ css
│  ├─ common.css   (공통, 헤더)
│  ├─ main.css     (메인 페이지 각 영역)
│  ├─ detail.css   (상품 상세 페이지)
│  └─ cart.css     (메인·상세 공통 장바구니)
├─ js
│  ├─ products.js  (6개 상품 데이터와 목록 구성)
│  ├─ cart.js      (공통 장바구니 상태와 화면)
│  ├─ main.js      (메인 상품 카드 생성과 담기)
│  └─ detail.js    (주소에 맞는 상품·옵션·추천 표시)
└─ images
```

## 참고

- 메인 상품 카드와 상세 페이지 모두 포트폴리오용 장바구니가 동작합니다.
- 상세 페이지는 학습용 데모이므로 실제 주문과 결제는 진행되지 않습니다.
- 헤더와 푸터의 일부 메뉴는 화면 구성을 위한 데모 링크입니다.
