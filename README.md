# NONFICTION 메인 페이지 클론코딩

향수 브랜드 논픽션(NONFICTION) 공식 사이트를 참고해 메인 페이지를 구현한 클론코딩 프로젝트입니다.
디자인과 이미지의 저작권은 원 브랜드에 있으며 포트폴리오 용도로만 사용했습니다.

## 프로젝트 정보

- 작업 유형: 개인 작업 (클론코딩)
- 사용 기술: HTML, CSS, JavaScript, Swiper
- 폰트: Playfair Display

## 페이지 구성

1. 상단 배너 + 헤더 (메가 메뉴)
2. 메인 배너 슬라이드
3. 상품 목록
4. 프로모션 배너 슬라이드
5. 향수 소개 슬라이드
6. 라인업 배너
7. 푸터

## 작업한 내용

- 헤더는 `position: fixed`로 고정했고, 스크롤을 내리거나 메뉴에 마우스를 올리면 배경이 흰색으로 바뀝니다.
- 메뉴에 마우스를 올리면 이미지가 들어간 메가 메뉴가 펼쳐집니다.
- 메인 배너와 향수 소개 부분은 Swiper 라이브러리로 슬라이드를 만들었습니다.
- 상품 이미지에 마우스를 올리면 다른 이미지로 바뀌고 장바구니 버튼이 아래에서 올라옵니다.
- 상품 목록은 PC 4열, 태블릿 3열, 모바일 2열로 바뀝니다. (기준: 1023px, 767px)
- 프로모션 배너는 PC용과 모바일용 이미지를 따로 만들어 화면 크기에 따라 보여줍니다.

## 어려웠던 점

**헤더 스타일 바꾸기**

헤더가 배너 이미지 위에 있어서 처음에는 흰 글씨, 스크롤하면 검은 글씨가 되어야 했습니다. 스크롤 위치가 50px을 넘으면 `scrolled` 클래스를 붙이고, CSS에서 이 클래스가 있을 때와 `:hover`일 때 같은 스타일이 적용되도록 했습니다.

**향수 슬라이드**

슬라이드 6개의 구조가 같고 이름, 설명, 이미지만 달라서 HTML을 반복해서 작성하지 않고 배열과 `forEach`를 사용했습니다. 새 향수를 추가할 때 배열에 정보를 한 항목만 추가하면 되도록 구성했습니다.

**PC / 모바일 배너 분리**

`.pc-only`, `.mobile-only` 클래스를 만들어 767px 이하에서는 PC용 배너를 숨기고 모바일용 배너를 보여줍니다.

## 폴더 구조

