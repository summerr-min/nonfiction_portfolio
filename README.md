# NONFICTION 메인 페이지 클론코딩

향수 브랜드 논픽션(NONFICTION) 공식 사이트를 참고해 메인 페이지를 구현한 클론코딩 프로젝트입니다.
디자인과 이미지의 저작권은 원 브랜드에 있으며 포트폴리오 용도로만 사용했습니다.

## 프로젝트 정보

- 작업 유형: 개인 작업 (클론코딩)
- 사용 기술: HTML, CSS, JavaScript, Swiper
- 폰트: Playfair Display

## 페이지 구성

1. 상단 배너 + 헤더 (메가 메뉴)
2. 메인 배너 슬라이드
3. 상품 목록
4. 프로모션 배너 슬라이드
5. 향수 소개 슬라이드
6. 라인업 배너
7. 푸터
8. 6개 상품이 함께 사용하는 상품 상세 페이지
9. 메인·상세 공통 장바구니

## 작업한 내용

- 헤더는 `position: fixed`로 고정했고, 스크롤을 내리거나 메뉴에 마우스를 올리면 배경이 흰색으로 바뀝니다.
- 메뉴에 마우스를 올리면 이미지가 들어간 메가 메뉴가 펼쳐집니다.
- 메인 배너와 향수 소개 부분은 Swiper 라이브러리로 슬라이드를 만들었습니다.
- 상품 이미지에 마우스를 올리면 다른 이미지로 바뀌고 장바구니 버튼이 아래에서 올라옵니다.
- 상품 목록은 PC 4열, 태블릿 3열, 모바일 2열로 바뀝니다. (기준: 1023px, 767px)
- 프로모션 배너는 PC용과 모바일용 이미지를 따로 만들어 화면 크기에 따라 보여줍니다.
- 상품 사진이나 이름을 누르면 상품 ID와 옵션이 주소에 포함되고, 하나의 `detail.html`이 6개 상품 정보를 바꾸어 표시합니다.
- 티어스 인 레인과 네롤리 드림은 향 노트와 스토리 콘텐츠를 강화하고, 나머지 상품은 구매 정보 중심으로 간결하게 구성했습니다.
- 메인과 상세 페이지는 같은 장바구니 모듈을 사용합니다. 어느 화면에서 담아도 수량과 합계가 함께 갱신됩니다.
- 장바구니는 `localStorage`에 저장되어 화면 이동이나 새로고침 후에도 선택한 상품이 유지됩니다.
- 모바일 메뉴, 모바일 하단 구매 버튼, 키보드 포커스와 ARIA 상태를 추가했습니다.

## 상세 페이지 학습 문서

상품 상세 페이지의 실행 순서와 JavaScript 메서드는
[`DETAIL_PAGE_GUIDE.md`](DETAIL_PAGE_GUIDE.md)에 비전공자도 따라갈 수 있도록 정리했습니다.

## 폴더 구조

```
nonfiction_portfolio
├─ index.html
├─ detail.html
├─ css
│  ├─ common.css   (공통, 헤더)
│  ├─ main.css     (메인 페이지 각 영역)
│  ├─ detail.css   (상품 상세 페이지)
│  └─ cart.css     (메인·상세 공통 장바구니)
├─ js
│  ├─ products.js  (6개 상품 데이터와 목록 구성)
│  ├─ cart.js      (공통 장바구니 상태와 화면)
│  ├─ main.js      (메인 상품 카드 생성과 담기)
│  └─ detail.js    (주소에 맞는 상품·옵션·추천 표시)
└─ images
```

## 참고

- 메인 상품 카드와 상세 페이지 모두 포트폴리오용 장바구니가 동작합니다.
- 상세 페이지는 학습용 데모이므로 실제 주문과 결제는 진행되지 않습니다.
